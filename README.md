# guia-metodologias-ageis
Este repositório foi desenvolvido como parte de um projeto acadêmico utilizando o NotebookLM para estudo, consolidação e engenharia de prompts aplicada ao aprendizado de metodologias ágeis.
O objetivo principal foi criar um material estruturado sobre frameworks ágeis amplamente utilizados no mercado, reunindo conceitos, comparações práticas, glossário técnico e prompts reutilizáveis para futuras revisões.
